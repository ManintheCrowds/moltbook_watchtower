## 3. Static / a11y / responsive

- **a11y:** Generator includes `<main>`, visually hidden table captions, and `aria-label` / `role="img"` on chart canvases. **MW-3 (2026-03-30):** each Chart.js canvas and word-cloud canvas has **`aria-describedby`** pointing to an **off-screen SR-only data table** (`table.sr-chart-table`, same metrics as the chart). Behavior time-series SR table caps at 300 rows with a caption when truncated. **Networks:** each graph sits in a **`role="region"`** (focusable, visible focus ring), with **nodes/edges SR tables** under `desc-networkGraph` / `desc-networkCommentGraph`, **`role="group"`** on the vis container, and **`aria-describedby`** including keyboard/pan-zoom guidance. Full WCAG AA or native keyboard graph traversal (vis-network limits) may still warrant manual audit or companion export (`export_network.py` in footer).  
- **Responsive (MW-7):** `@media (max-width: 720px)` tightens padding, heading scale, table cell size, network panel height (`min(320px, 55vh)`), and footer rhythm; marker `/* MW-7 responsive */` in generator CSS for regression grep. Wide tables may still horizontal-scroll — acceptable for dense metrics.  
- **Print (MW-6):** `@media print` in generated CSS — light paper background, `break-inside: avoid` on charts/networks/tables, off-screen **SR tables** reset to **static** so numeric/word data appears on printed/PDF output.  
- **Visual (MW-4):** Dark utilitarian theme; JetBrains Mono + Source Sans 3 via Google Fonts; design tokens on `:root`; subtle main entrance animation unless `prefers-reduced-motion: reduce`.  
- **Security:** Script header states “no raw secrets”; verify queries never embed PII into HTML strings.

## 7. Post-MW-3 verification (MW-5)

Use a **real DB** (copy), run `python scripts/generate_dashboard_html.py`, open **`exports/dashboard.html`** in a browser (not only the fixture-driven e2e).

### Screen reader / AT spot-check

- **NVDA (Windows):** Start NVDA, open the file or served URL, navigate by landmarks (`main`), headings, and tables; confirm chart canvases expose **`aria-describedby`** and off-screen **data tables**; tab to **network regions** and confirm node/edge tables and instructions are reachable in reading order.
- **JAWS (Windows):** Same journey; verify table navigation (Ctrl+Alt+arrows) on SR chart tables where applicable.
- **VoiceOver (macOS):** Safari, VO+U (rotor) for landmarks/headings/tables; spot-check network **regions** and graph **group** labels.

Record pass/fail in session notes or PR when performing this check. **MW-5** (wave-5) is **closed** in the rollout YAML once the operator has executed §7 at least once on a real DB copy.

### Optional: deeper keyboard on the vis canvas

vis-network does not guarantee full graph exploration by keyboard. Custom JS (e.g. focus moves, arrow-key pan) is **optional** and only worth it if product accepts maintenance cost and library limits. SR **node/edge tables** remain the accessible source of truth.

### Bulk / offline network data (companion to the HTML dashboard)

From the repo root (with `DATA_DIR` / DB as usual), run **`python scripts/export_network.py`**. Writes under **`exports/`** next to the DB (gitignored): **`network_edges.csv`** (edge list) and **`network.graphml`** (nodes/edges for Gephi/Cytoscape). The generated HTML **footer** points to this script and to [`docs/TELEMETRY_AND_NETWORK_VIZ.md`](../TELEMETRY_AND_NETWORK_VIZ.md) for tool-specific import.
