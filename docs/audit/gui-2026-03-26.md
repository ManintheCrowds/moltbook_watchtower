---

## 3. Static / a11y / responsive

- **a11y:** Generator now includes `<main>`, visually hidden table captions, and `aria-label` / `role="img"` on chart canvases (partial MW-3); charts/networks remain limited for screen readers — full WCAG AA may still need data-table alternatives or companion CSV export (footer already points to `export_network.py`).  
- **Responsive:** `main` uses horizontal scroll when needed; tables are styled (`data-table`) with max-width container — small screens may still scroll wide tables — manual check recommended.  
- **Visual (MW-4):** Dark utilitarian theme; JetBrains Mono + Source Sans 3 via Google Fonts; design tokens on `:root`; subtle main entrance animation unless `prefers-reduced-motion: reduce`.  
- **Security:** Script header states “no raw secrets”; verify queries never embed PII into HTML strings.
